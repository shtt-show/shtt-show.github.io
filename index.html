Because version control doesn't have to be a shitshow

Finally, Version Control That Makes Sense

SHTT simplifies history tracking with an intuitive approach that actually works. No more fighting with complex branching strategies or cryptic commit messages.

🎯 Simple & Intuitive

Designed for humans, not git wizards. Track changes without the mental overhead of traditional version control systems.

🚀 Lightning Fast

Built in Rust for maximum performance. Operations that take minutes in other tools happen in seconds with SHTT.

🧠 Smart Defaults

Sensible defaults that work out of the box. Spend time building, not configuring your version control system.

Get Started

Install SHTT and start tracking changes the sane way:

# Install via cargo cargo install shtt # Initialize a new project shtt init # Track your first change shtt add "Initial commit"
